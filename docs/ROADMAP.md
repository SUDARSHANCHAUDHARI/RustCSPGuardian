# Roadmap

This is a solo-maintained roadmap. Items are practical possibilities, not promises.

## Planned

- Add clearer remediation hints for common CSP and X-Frame-Options failures.
- Add batch summary totals for blocked, warning, and unknown URLs.
- Add an option to save HTML reports to a chosen path.

## Maybe Later

- Add baseline comparison for repeated scans.
- Add a compact Markdown output mode.
- Add domain-level grouping for batch checks.

## Not Planned

- Browser automation or JavaScript rendering.
- A hosted scanning service.
- GitHub Actions workflow files.

## Feature Blog Angles

- "How iframe embeds fail in production and how to check them before release"
- "CSP frame-ancestors vs X-Frame-Options: the practical version"
- "Building a small Rust CLI that produces terminal, JSON, and HTML reports"
