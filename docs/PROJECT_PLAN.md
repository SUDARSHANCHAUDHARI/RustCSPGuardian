# Project Plan

## Goal

Build a product-style SaaS scanner that helps developers understand website security headers, iframe compatibility, and CSP remediation steps.

## MVP

- Load offline header fixtures or scan live URLs.
- Analyze CSP quality, iframe policy, HSTS, content-type hardening, CORS, and mixed content.
- Generate findings with severity and evidence.
- Produce a risk score, letter grade, header matrix, remediation plan, and Markdown report.

## Deep Polish Scope

- Add richer CSP directive checks.
- Add iframe compatibility posture.
- Add prioritized remediation plan output.
- Add Docker demo workflow.
- Replace placeholder docs with architecture and safety notes.
